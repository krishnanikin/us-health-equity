# US Health Equity documentation!

## Description

Vaccination (MMR, flu), major-disease mortality by race, household income and college attainment, and healthcare spending trends in the US, 2015-present.

## Commands

The Makefile contains the central entry points: `make pipeline` rebuilds all data and models, `make dashboard` launches the Streamlit dashboard, and `make test` runs the test suite. See [Getting started](getting-started.md).
